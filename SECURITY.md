# Security Policy

## Scope

This is a public defensive-security portfolio repository. It should never contain live credentials, private tenant information or sensitive production data.

## Please Do Not Commit

- passwords
- API keys
- access tokens
- private keys
- service-principal secrets
- connection strings
- tenant secrets
- sensitive personal data
- unredacted customer or organisation information

## Reporting a Sensitive Finding

If you notice accidentally exposed sensitive information, please do not open a public issue containing the secret or reproducing it.

Contact the repository owner privately through the professional contact channels listed on the GitHub profile or portfolio.

## Lab Safety

All testing documented in this repository should be performed only in environments where the tester has explicit authorisation.

The repository is intended for defensive monitoring, detection engineering and incident-response learning.
